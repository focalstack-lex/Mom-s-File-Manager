# To do list Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A To do screen in Tote: tasks with an optional due day, weekly, monthly or quarterly repeats, attached files from the index, Undo for tick and delete, one morning reminder, and a tasks store that survives a damaged database.

**Architecture:** A new native module `tasks.rs` owns the rules and the store. The store is its own SQLite file (`tasks.sqlite`) attached to the existing connection as schema `todo`, so the one-mutex discipline stays and `index::relocate` can update attachments. The worker's loop runs a 15-minute housekeeping check (purge, daily snapshot, reminder). The renderer gets a `useTodo` store, a `TodoView`, a `TaskRow` with details opened in place, and an `AttachDialog` that reuses the `find` command.

**Tech Stack:** Tauri 2, Rust (rusqlite 0.40 bundled, chrono 0.4, tauri-plugin-notification), React 18 + TypeScript + zustand, vitest, Playwright drives (`scripts/verify-ui.mjs`, `scripts/verify-native.mjs`).

**Spec:** `docs/superpowers/specs/2026-10-14-todo-list-design.md`

## Global Constraints

- No emoji and no em or en dash anywhere (code, copy, comments, commits, docs). `npm run verify:text` and ESLint enforce it.
- Rust: no `unwrap`, `expect` or `panic` outside tests (clippy denies them). Every command that touches the database is `async` and runs through `blocking(...)`.
- Never call `settings_of` (or anything that locks the database) while a `core.db()` guard is alive. Read settings first, then lock.
- Validation lives on the native side; the renderer only displays results.
- Before any cargo or tauri command, set `$env:TAURI_CONFIG = '{"bundle":{"icon":["E:/PROJECTS/tote-icons/32x32.png","E:/PROJECTS/tote-icons/128x128.png","E:/PROJECTS/tote-icons/128x128@2x.png","E:/PROJECTS/tote-icons/icon.icns","E:/PROJECTS/tote-icons/icon.ico"]}}'` (the apostrophe in the checkout path breaks the icon step otherwise). Build in the release profile only (`cargo test --release`), E: has little free space.
- Copy is plain, short, and in the house voice. One primary action per screen (Add).
- Error code for "task not found" is `validation` with the message "That task is no longer on the list." (`describeError` maps `notFound` to a sentence about files).

//! The To do list (docs/superpowers/specs/2026-10-14-todo-list-design.md):
//! tasks with an optional due day, repeats, attached files and one morning
//! reminder. Tasks live in their own file, tasks.sqlite, attached to the main
//! connection as schema `todo`, so a rebuild of the index never takes them
//! along; a daily snapshot brings them back if that file is ever damaged.

use crate::commands::DateRange;
use crate::error::{Result, ToteError};
use chrono::{Days, Months, NaiveDate, NaiveDateTime, Timelike};
use serde::{Deserialize, Serialize};

const TITLE_MAX: usize = 200;
const REMIND_FROM_HOUR: u32 = 7;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Repeat {
    Never,
    Week,
    Month,
    Quarter,
}

impl Repeat {
    fn as_str(self) -> &'static str {
        match self {
            Repeat::Never => "never",
            Repeat::Week => "week",
            Repeat::Month => "month",
            Repeat::Quarter => "quarter",
        }
    }

    fn from_db(text: &str) -> Self {
        match text {
            "week" => Repeat::Week,
            "month" => Repeat::Month,
            "quarter" => Repeat::Quarter,
            _ => Repeat::Never,
        }
    }
}

/// "YYYY-MM-DD" as a calendar day, the form the quarters already use.
pub fn parse_day(text: &str) -> Option<NaiveDate> {
    NaiveDate::parse_from_str(text.trim(), "%Y-%m-%d").ok()
}

fn day_text(day: NaiveDate) -> String {
    day.format("%Y-%m-%d").to_string()
}

/// Quarters with two readable dates in order, earliest first.
pub fn usable_quarters(quarters: &[DateRange]) -> Vec<(NaiveDate, NaiveDate)> {
    let mut out: Vec<(NaiveDate, NaiveDate)> = quarters
        .iter()
        .filter_map(|q| Some((parse_day(&q.start)?, parse_day(&q.end)?)))
        .filter(|(start, end)| start <= end)
        .collect();
    out.sort();
    out
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Next {
    Due(NaiveDate),
    /// A quarterly task in the last quarter Settings knows about.
    NoNextQuarter,
}

/// When the next copy of a repeating task is due.
pub fn next_due(due: NaiveDate, repeat: Repeat, quarters: &[DateRange]) -> Option<Next> {
    match repeat {
        Repeat::Never => None,
        Repeat::Week => due.checked_add_days(Days::new(7)).map(Next::Due),
        // chrono uses the month's last day when the day does not exist (31 January to 28 February).
        Repeat::Month => due.checked_add_months(Months::new(1)).map(Next::Due),
        Repeat::Quarter => Some(next_quarter_due(due, &usable_quarters(quarters))),
    }
}

/// Same number of days before the end of the next quarter as this one was,
/// never before that quarter starts. A day outside every quarter goes to the
/// end of the next quarter that starts after it.
fn next_quarter_due(due: NaiveDate, quarters: &[(NaiveDate, NaiveDate)]) -> Next {
    // Sorted by start, so the first match is the soonest.
    let starting_after = |day: NaiveDate| quarters.iter().find(|(start, _)| *start > day).copied();
    match quarters.iter().find(|(start, end)| *start <= due && due <= *end) {
        Some(&(_, end)) => match starting_after(end) {
            Some((start, next_end)) => {
                let before_end = end.signed_duration_since(due).num_days();
                let day = u64::try_from(before_end).ok().and_then(|days| next_end.checked_sub_days(Days::new(days))).unwrap_or(next_end);
                Next::Due(day.max(start))
            }
            None => Next::NoNextQuarter,
        },
        None => match starting_after(due) {
            Some((_, next_end)) => Next::Due(next_end),
            None => Next::NoNextQuarter,
        },
    }
}

/// A task title: one line, 1 to 200 characters.
pub fn clean_title(title: &str) -> Result<String> {
    let one_line: String = title.chars().map(|c| if c.is_control() { ' ' } else { c }).collect();
    let cleaned = one_line.trim();
    if cleaned.is_empty() {
        return Err(ToteError::validation("Type what needs doing first."));
    }
    if cleaned.chars().count() > TITLE_MAX {
        return Err(ToteError::validation("That is too long for one task. Keep it under 200 letters."));
    }
    Ok(cleaned.to_string())
}

/// An optional due day; empty means no date.
pub fn clean_due(due: Option<&str>) -> Result<Option<NaiveDate>> {
    match due.map(str::trim).filter(|text| !text.is_empty()) {
        None => Ok(None),
        Some(text) => parse_day(text).map(Some).ok_or_else(|| ToteError::validation("That date could not be read.")),
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Reminder {
    pub title: String,
    pub body: String,
    pub due_today: usize,
    pub overdue: usize,
}

/// The morning reminder, if one is due now: from 07:00, at most once a day,
/// only with the notifications switch on and something due today or overdue.
/// `open` is every open task that has a due day.
pub fn reminder(now: NaiveDateTime, last: Option<NaiveDate>, open: &[(String, NaiveDate)], enabled: bool) -> Option<Reminder> {
    let today = now.date();
    if !enabled || now.hour() < REMIND_FROM_HOUR || last == Some(today) {
        return None;
    }
    let due_today: Vec<&str> = open.iter().filter(|(_, due)| *due == today).map(|(title, _)| title.as_str()).collect();
    let overdue = open.iter().filter(|(_, due)| *due < today).count();
    if due_today.is_empty() && overdue == 0 {
        return None;
    }
    let body = if due_today.is_empty() {
        if overdue == 1 { "1 task is overdue.".to_string() } else { format!("{overdue} tasks are overdue.") }
    } else {
        let shown = due_today.iter().take(3).copied().collect::<Vec<_>>().join(", ");
        let more = due_today.len().saturating_sub(3);
        let mut text = if more > 0 { format!("{shown} and {more} more.") } else { format!("{shown}.") };
        if overdue > 0 {
            text.push_str(&format!(" Also {overdue} overdue."));
        }
        text
    };
    Some(Reminder { title: "To do today".into(), body, due_today: due_today.len(), overdue })
}

/// Opens tasks.sqlite beside the main database and attaches it as `todo`.
/// A file that cannot be read is set aside (never deleted) and the daily
/// snapshot takes its place; without a healthy snapshot the list starts empty.
pub fn open_store(conn: &Connection, data_dir: &Path) -> Result<Option<Restored>> {
    let file = data_dir.join(FILE);
    let mut restored = None;
    if file.exists() && !healthy(&file) {
        set_aside(data_dir, db::now())?;
        let backup = data_dir.join(BACKUP);
        if backup.exists() && healthy(&backup) {
            std::fs::copy(&backup, &file)?;
            log::warn!("{FILE} could not be read; restored it from {BACKUP}");
            restored = Some(Restored::Snapshot);
        } else {
            log::warn!("{FILE} could not be read and no healthy snapshot exists; the list starts empty");
            restored = Some(Restored::Empty);
        }
    }
    conn.execute("ATTACH DATABASE ?1 AS todo", [paths::display(&file)])?;
    conn.pragma_update(Some(rusqlite::DatabaseName::Attached("todo")), "journal_mode", "WAL")?;
    conn.execute_batch(SCHEMA)?;
    Ok(restored)
}

/// Opened read-write, like the main database, so a WAL left by a crash is
/// recovered instead of being mistaken for damage.
fn healthy(file: &Path) -> bool {
    let Ok(conn) = Connection::open(file) else { return false };
    conn.query_row("PRAGMA integrity_check", [], |row| row.get::<_, String>(0)).map(|ok| ok == "ok").unwrap_or(false)
}

fn set_aside(data_dir: &Path, stamp: i64) -> Result<()> {
    for suffix in ["", "-wal", "-shm"] {
        let from = data_dir.join(format!("{FILE}{suffix}"));
        if from.exists() {
            std::fs::rename(&from, data_dir.join(format!("tasks.damaged-{stamp}.sqlite{suffix}")))?;
        }
    }
    Ok(())
}

    conn.execute_batch("ATTACH DATABASE ':memory:' AS todo")?;

    Ok(())
}

/// Copies the list to tasks.backup.sqlite at most once a day, through a
/// temporary file so a failed copy never replaces a good one.
pub fn snapshot(conn: &Connection, data_dir: &Path, today: NaiveDate) -> Result<bool> {
    let stamp = day_text(today);
    if db::get_setting(conn, SNAPSHOT_KEY)?.as_deref() == Some(stamp.as_str()) {
        return Ok(false);
    }
    let temp = data_dir.join("tasks.backup.tmp");
    if temp.exists() {
        std::fs::remove_file(&temp)?;
    }
    conn.execute("VACUUM todo INTO ?1", [paths::display(&temp)])?;
    std::fs::rename(&temp, data_dir.join(BACKUP))?;
    db::set_setting(conn, SNAPSHOT_KEY, &stamp)?;
    Ok(true)
}

/// Removes tasks deleted over a week ago and tasks done over 30 days ago.
pub fn purge(conn: &Connection, now: i64) -> Result<usize> {

        params![now - DELETED_KEEP_SECS, now - DONE_KEEP_SECS],
    )?)
}

fn files_of(conn: &Connection, id: i64) -> Result<Vec<TaskFile>> {
    let mut stmt = conn.prepare("SELECT path FROM todo.task_files WHERE task_id = ?1 ORDER BY added_at, path")?;
    let paths = stmt.query_map([id], |row| row.get::<_, String>(0))?.collect::<std::result::Result<Vec<_>, _>>()?;
    Ok(paths
        .into_iter()
        .map(|path| {
            let file = Path::new(&path);
            let ext = sorter::extension(file);
            let name = file.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_default();
            let kind = sorter::classify(&ext).as_str().to_string();
            let missing = !file.is_file();
            TaskFile { path, name, ext, kind, missing }
        })
        .collect())
}

pub fn get(conn: &Connection, id: i64) -> Result<Task> {
    let task = conn
        .query_row(&format!("SELECT {COLUMNS} FROM todo.tasks WHERE id = ?1 AND deleted_at IS NULL"), [id], row_to_task)
        .optional()?
        .ok_or_else(not_found)?;
    Ok(Task { files: files_of(conn, id)?, ..task })
}

/// Open tasks (dated first, by day, then oldest first) and tasks done in the last 30 days.
pub fn list(conn: &Connection, now: i64) -> Result<Vec<Task>> {
    let mut stmt = conn.prepare(&format!(
        "SELECT {COLUMNS} FROM todo.tasks WHERE deleted_at IS NULL AND (done_at IS NULL OR done_at >= ?1) ORDER BY done_at IS NOT NULL, due IS NULL, due, created_at, id"

fn check_repeat(repeat: Repeat, due: Option<NaiveDate>, quarters: &[DateRange]) -> Result<()> {
    if repeat == Repeat::Never {
        return Ok(());
    }
    if due.is_none() {
        return Err(ToteError::validation("Pick a due date first. A task needs one to repeat."));
    }
    if repeat == Repeat::Quarter && usable_quarters(quarters).is_empty() {
        return Err(ToteError::validation("Add the quarter dates in Settings first."));
    }
    Ok(())
}

pub fn update(conn: &Connection, id: i64, title: &str, due: Option<&str>, repeat: Repeat, quarters: &[DateRange], now: i64) -> Result<Task> {
    let title = clean_title(title)?;
    let due = clean_due(due)?;
    check_repeat(repeat, due, quarters)?;
    let changed = conn.execute(
        "UPDATE todo.tasks SET title = ?2, due = ?3, repeat = ?4, edited_at = ?5 WHERE id = ?1 AND deleted_at IS NULL",
        params![id, title, due.map(day_text), repeat.as_str(), now],
    )?;
    if changed == 0 {
        return Err(not_found());
    }
    get(conn, id)
}

/// Ticks a task off. A repeating one gets its next copy in the same
/// transaction, so the list never shows one without the other.
pub fn complete(conn: &Connection, id: i64, quarters: &[DateRange], now: i64) -> Result<Completed> {
    let tx = conn.unchecked_transaction()?;
    let task = get(&tx, id)?;
    if task.done_at.is_some() {
        return Ok(Completed { task, next: None, no_next_quarter: false });
    }
    tx.execute("UPDATE todo.tasks SET done_at = ?2 WHERE id = ?1", params![id, now])?;
    let mut next_id = None;
    let mut no_next_quarter = false;
    if let Some(due) = task.due.as_deref().and_then(parse_day) {
        match next_due(due, task.repeat, quarters) {
            Some(Next::Due(day)) => {
                tx.execute(
                    "INSERT INTO todo.tasks(title, due, repeat, repeated_from, created_at) VALUES(?1, ?2, ?3, ?4, ?5)",
                    params![task.title, day_text(day), task.repeat.as_str(), id, now],
                )?;
                next_id = Some(tx.last_insert_rowid());
            }
            Some(Next::NoNextQuarter) => no_next_quarter = true,
            None => {}
        }
    }
    tx.commit()?;
    Ok(Completed { task: get(conn, id)?, next: next_id.map(|n| get(conn, n)).transpose()?, no_next_quarter })
}

/// Undo of a tick: back on the list, and the copy that tick made goes, but
/// only while she has not touched it (edited, done or given files).
pub fn reopen(conn: &Connection, id: i64) -> Result<()> {
    let tx = conn.unchecked_transaction()?;
    if tx.execute("UPDATE todo.tasks SET done_at = NULL WHERE id = ?1 AND deleted_at IS NULL", [id])? == 0 {
        return Err(not_found());
    }
    tx.execute(
        "DELETE FROM todo.tasks WHERE repeated_from = ?1 AND edited_at IS NULL AND done_at IS NULL AND deleted_at IS NULL \
         AND NOT EXISTS (SELECT 1 FROM todo.task_files f WHERE f.task_id = todo.tasks.id)",
        [id],
    )?;
    tx.commit()?;
    Ok(())
}

pub fn delete(conn: &Connection, id: i64, now: i64) -> Result<()> {
    if conn.execute("UPDATE todo.tasks SET deleted_at = ?2 WHERE id = ?1 AND deleted_at IS NULL", params![id, now])? == 0 {
        return Err(not_found());
    }
    Ok(())
}

pub fn restore(conn: &Connection, id: i64) -> Result<()> {
    if conn.execute("UPDATE todo.tasks SET deleted_at = NULL WHERE id = ?1", [id])? == 0 {
        return Err(not_found());
    }
    Ok(())
}

/// Attaches a file inside her folders (the same boundary as Open).
pub fn attach_file(conn: &Connection, roots: &Roots, id: i64, path: &Path, now: i64) -> Result<Task> {
    let file = roots.confine(path)?;
    if !file.is_file() {
        return Err(ToteError::new(ErrorCode::NotFound, "That file could not be found.").with_path(paths::display(&file)));
    }
    get(conn, id)?;
    conn.execute("INSERT OR IGNORE INTO todo.task_files(task_id, path, added_at) VALUES(?1, ?2, ?3)", params![id, paths::display(&file), now])?;
    get(conn, id)
}

pub fn detach_file(conn: &Connection, id: i64, path: &str) -> Result<Task> {
    conn.execute("DELETE FROM todo.task_files WHERE task_id = ?1 AND path = ?2", params![id, path])?;
    get(conn, id)
}

}

/// The To do list's housekeeping: clear old done and deleted tasks, keep the
/// day's snapshot, and show the morning reminder (rules in tasks.rs). Runs
/// when the worker starts and every 15 minutes, so a laptop first opened at
/// 14:00 is reminded then.
fn tasks_check(core: &Arc<Core>, app: &AppHandle) {
    // Settings first: the database mutex is not reentrant.
    let notifications = crate::commands::settings_of(core).notifications;
    let now = chrono::Local::now().naive_local();
    let reminder = {
        let Ok(conn) = core.db() else { return };
        if let Err(error) = tasks::purge(&conn, crate::db::now()) {
            log::warn!("tasks purge: {error}");
        }
        match tasks::snapshot(&conn, &core.data_dir, now.date()) {
            Ok(true) => log::info!("tasks snapshot saved"),
            Ok(false) => {}
            Err(error) => log::warn!("tasks snapshot: {error}"),
        }
        let last = crate::db::get_setting(&conn, tasks::REMINDED_KEY).ok().flatten().and_then(|day| tasks::parse_day(&day));
        match tasks::open_with_due(&conn) {
            Ok(open) => tasks::reminder(now, last, &open, notifications),
            Err(error) => {
                log::warn!("tasks reminder: {error}");
                None
            }
        }
    };
    let Some(reminder) = reminder else { return };
    use tauri_plugin_notification::NotificationExt;
    if let Err(error) = app.notification().builder().title(&reminder.title).body(&reminder.body).show() {
        // Not recorded, so the next check tries again.
        log::warn!("reminder notification: {error}");
        return;
    }
    log::info!("morning reminder shown ({} due today, {} overdue)", reminder.due_today, reminder.overdue);
    if let Ok(conn) = core.db() {
        if let Err(error) = crate::db::set_setting(&conn, tasks::REMINDED_KEY, &now.date().format("%Y-%m-%d").to_string()) {
            log::warn!("reminder day not saved: {error}");
        }
    }
}

// The To do list in plain words (spec 2026-10-14): which group a task sits
// in, when it is due, how it repeats, and whether "Every quarter" can be
// offered. Pure functions; "now" is passed in so tests can fix the day.

import { parseDay } from "./dates";
import type { DayGroup } from "./paging";
import type { Repeat, Settings, Task } from "./types";

export const TASK_GROUPS = ["Overdue", "Today", "Tomorrow", "This week", "Later", "No date"] as const;
export type TaskGroup = (typeof TASK_GROUPS)[number];

const MONTHS = ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"];
const DAYS = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"];

function startOfDay(date: Date): Date {
  return new Date(date.getFullYear(), date.getMonth(), date.getDate());
}

/** Whole days from today to `day` (rounded, so a daylight saving change does not shift it). */
function daysFrom(today: Date, day: Date): number {
  return Math.round((day.getTime() - today.getTime()) / 86_400_000);
}

export function groupOf(due: string | null, now: Date = new Date()): TaskGroup {
  const day = due ? parseDay(due) : null;
  if (!day) return "No date";
  const today = startOfDay(now);
  const diff = daysFrom(today, day);
  if (diff < 0) return "Overdue";
  if (diff === 0) return "Today";
  if (diff === 1) return "Tomorrow";
  // The rest of the Monday to Sunday week.
  const toSunday = (7 - today.getDay()) % 7;
  return diff <= toSunday ? "This week" : "Later";
}

function byDue(a: Task, b: Task): number {
  if (a.due !== b.due) {
    if (a.due === null) return 1;
    if (b.due === null) return -1;
    return a.due < b.due ? -1 : 1;
  }
  return a.createdAt - b.createdAt || a.id - b.id;
}

/** Open tasks in their groups, in group order, empty groups left out. */
export function groupTasks(tasks: Task[], now: Date = new Date()): DayGroup<Task>[] {
  const open = tasks.filter((t) => t.doneAt === null).sort(byDue);
  return TASK_GROUPS.map((title) => ({ title, items: open.filter((t) => groupOf(t.due, now) === title) })).filter((g) => g.items.length > 0);
}

function dayMonth(day: Date, now: Date): string {
  const text = `${day.getDate()} ${MONTHS[day.getMonth()]}`;
  return day.getFullYear() === now.getFullYear() ? text : `${text} ${day.getFullYear()}`;
}

/** "due today", "due Friday", "due 30 October", "was due yesterday". */
export function dueWords(due: string | null, now: Date = new Date()): string | null {
  const day = due ? parseDay(due) : null;
  if (!day) return null;
  const diff = daysFrom(startOfDay(now), day);
  if (diff === 0) return "due today";
  if (diff === 1) return "due tomorrow";
  if (diff === -1) return "was due yesterday";
  if (diff > 1 && diff < 7) return `due ${DAYS[day.getDay()]}`;
  if (diff < -1 && diff > -7) return `was due ${DAYS[day.getDay()]}`;
  return `${diff < 0 ? "was due" : "due"} ${dayMonth(day, now)}`;
}

/** "14 November", for the toast after a repeating task is ticked. */
export function dayWords(due: string, now: Date = new Date()): string {
  const day = parseDay(due);
  return day ? dayMonth(day, now) : due;
}

export function repeatWords(repeat: Repeat): string | null {
  switch (repeat) {
    case "week":
      return "every week";
    case "month":
      return "every month";
    case "quarter":
      return "every quarter";
    default:
      return null;
  }
}

export function filesWords(count: number): string | null {
  if (count === 0) return null;
  return count === 1 ? "1 file" : `${count} files`;
}

/** The one quiet line under a task's title. Done tasks keep only the repeat and files. */
export function taskMeta(task: Task, now: Date = new Date()): string {
  return [task.doneAt === null ? dueWords(task.due, now) : null, repeatWords(task.repeat), filesWords(task.files.length)].filter(Boolean).join(" \u00b7 ");
}

/** "Every quarter" needs at least one quarter with both dates in Settings. */
export function hasQuarters(settings: Settings): boolean {
  return settings.quarters.some((q) => {
    const start = parseDay(q.start);
    const end = parseDay(q.end);
    return Boolean(start && end && start <= end);
  });
}

import { ipc } from "../lib/ipc";
import { dayWords } from "../lib/todo";
import type { Repeat, Task } from "../lib/types";
import { useApp } from "./app";

interface TodoStore {
  tasks: Task[] | null;
  /** The task whose details are open, one at a time. */
  openId: number | null;
  load(): Promise<void>;
  setOpen(id: number | null): void;
  add(title: string, due: string | null): Promise<boolean>;
  update(task: Task, patch: { title?: string; due?: string | null; repeat?: Repeat }): Promise<void>;
  complete(task: Task): Promise<void>;
  reopen(id: number): Promise<void>;
  remove(task: Task): Promise<void>;
  restore(id: number): Promise<void>;
  attach(id: number, path: string): Promise<boolean>;
  detach(id: number, path: string): Promise<void>;
}

const fail = (error: unknown) => useApp.getState().fail(error);

export const useTodo = create<TodoStore>((set, get) => ({
  tasks: null,
  openId: null,
  load: async () => {
    try {
      set({ tasks: await ipc.tasks() });
    } catch (error) {
      fail(error);
    }
  },
  setOpen: (openId) => set({ openId }),
  add: async (title, due) => {
    try {
      await ipc.addTask(title, due);
      await get().load();
      return true;
    } catch (error) {
      fail(error);
      return false;
    }
  },
  update: async (task, patch) => {
    const due = patch.due !== undefined ? patch.due : task.due;
    // Without a date nothing can repeat, so clearing the date stops the repeat.
    const repeat = due === null ? "never" : (patch.repeat ?? task.repeat);
    try {
      await ipc.updateTask(task.id, patch.title ?? task.title, due, repeat);
    } catch (error) {
      fail(error);
    }
    await get().load();
  },
  complete: async (task) => {
    try {
      const done = await ipc.completeTask(task.id);
      await get().load();
      const text = done.next?.due ? `Done. Next one is due ${dayWords(done.next.due)}.` : done.noNextQuarter ? "Done. There is no next quarter in Settings, so it will not repeat." : "Done.";
      useApp.getState().toast(text, "info", undefined, undefined, { action: "reopen", id: task.id });
    } catch (error) {
      fail(error);
    }
  },
  reopen: async (id) => {
    try {
      await ipc.reopenTask(id);
    } catch (error) {
      fail(error);
    }
    await get().load();
  },
  remove: async (task) => {
    try {
      await ipc.deleteTask(task.id);
      if (get().openId === task.id) set({ openId: null });
      await get().load();
      useApp.getState().toast("Task deleted.", "info", undefined, undefined, { action: "restore", id: task.id });
    } catch (error) {
      fail(error);
    }
  },
  restore: async (id) => {
    try {
      await ipc.restoreTask(id);
    } catch (error) {
      fail(error);
    }
    await get().load();
  },
  attach: async (id, path) => {
    try {
      await ipc.attachFile(id, path);
      await get().load();
      return true;

      fail(error);
      return false;

// Attach a file to a task: a search over the same index as Find. Clicking a
// file attaches it and closes the dialog.

import { useEffect, useState } from "react";
import { describeError } from "../lib/errors";
import { locationLine } from "../lib/format";
import { ipc } from "../lib/ipc";
import type { FileRow } from "../lib/types";
import { useTodo } from "../store/todo";
import { Dialog } from "./Dialog";
import { KindIcon } from "./icons";

const LIMIT = 20;

export function AttachDialog({ taskId, roots, onClose }: { taskId: number; roots: string[]; onClose(): void }) {
  const attach = useTodo((s) => s.attach);
  const [query, setQuery] = useState("");
  const [found, setFound] = useState<{ query: string; rows: FileRow[] } | null>(null);
  const [error, setError] = useState<string | null>(null);

  // A short pause after typing, so each word is one search, as on Find.
  useEffect(() => {
    const wanted = query.trim();
    if (wanted === "") return undefined;
    let live = true;
    const timer = window.setTimeout(() => {
      ipc
        .find(wanted, { kinds: [], sources: [] })
        .then((result) => {
          if (!live) return;
          setFound({ query: wanted, rows: result.groups.map((g) => g.latest).slice(0, LIMIT) });
          setError(null);
        })
        .catch((e: unknown) => {
          if (live) setError(describeError(e));
        });
    }, 200);
    return () => {
      live = false;
      window.clearTimeout(timer);
    };
  }, [query]);

  const wanted = query.trim();
  const rows = wanted !== "" && found ? found.rows : [];
  const searched = found !== null && found.query === wanted;

  const pick = async (path: string) => {
    if (await attach(taskId, path)) onClose();
  };

  return (
    <Dialog title="Attach a file" onClose={onClose} testId="attach-dialog">
      <div className="field">
        <label htmlFor="attach-search">Search your files</label>
        <input id="attach-search" value={query} onChange={(e) => setQuery(e.target.value)} placeholder="A name, or a word inside the file" autoComplete="off" data-testid="attach-search" />
      </div>
      {rows.length > 0 && (
        <ul className="folder-list" aria-label="Files found">
          {rows.map((row) => (
            <li key={row.path}>
              <button type="button" className="folder-option attach-option" onClick={() => void pick(row.path)} data-testid="attach-option">
                <KindIcon kind={row.kind} size={20} />
                <span className="attach-text">
                  <span className="attach-name">{row.name}</span>
                  <span className="hint">{locationLine(row.parent, roots)}</span>
                </span>
              </button>
            </li>
          ))}
        </ul>
      )}
      {searched && rows.length === 0 && <p className="field-note">Nothing found. Try another word.</p>}
      {error && <p className="field-error">{error}</p>}
      <div className="dialog-actions">
        <button type="button" className="button" onClick={onClose}>
          Cancel
        </button>
      </div>
    </Dialog>
  );
}

type MockTask = Task & { repeatedFrom?: number; edited?: boolean; deleted?: boolean };
let tasks: MockTask[] = [];
let nextTask = 1;
const pad = (n: number) => String(n).padStart(2, "0");
const dayText = (d: Date) => `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
/** The next due day for weekly and monthly repeats, as tasks.rs computes it. */
function nextDay(due: string, repeat: Repeat): string | null {
  const [y, m, d] = due.split("-").map(Number);
  if (repeat === "week") return dayText(new Date(y, m - 1, d + 7));
  if (repeat === "month") return dayText(new Date(y, m, Math.min(d, new Date(y, m + 1, 0).getDate())));
  return null;
}
function taskById(id: unknown): MockTask {
  const task = tasks.find((t) => t.id === id && !t.deleted);
  if (!task) throw { code: "validation", message: "That task is no longer on the list." };
  return task;
}
const plain = ({ repeatedFrom: _r, edited: _e, deleted: _d, ...task }: MockTask): Task => ({ ...task, files: [...task.files] });
